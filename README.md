# 사주 궁합 계산기

양력 생년월일을 넣으면 사주팔자, 오행 분포, 운세, 부족한 기운 보완법이 나오고, 두 명을 함께 보면 궁합을 봅니다.

- 사이트: https://peacanes-tech.github.io/saju-calculator/
- 계산은 모두 브라우저 안에서 이뤄지며 입력한 정보는 전송되지 않습니다.
- 사주 풀이는 재미와 자기 점검용 전통 해석이며 의료·투자·법률 판단을 대신하지 않습니다.

## 사용한 오픈소스

사주 계산 엔진은 [NomaDamas/k-skill](https://github.com/NomaDamas/k-skill)의 `saju-fortune` 패키지(MIT License)를 그대로 묶어 넣었습니다.
